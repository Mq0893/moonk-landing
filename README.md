# MoonCroak (MOONK) — Sample Memecoin Landing Page

A polished, responsive, static memecoin landing page built with vanilla HTML, CSS and JavaScript. Brand, ticker and token details are fictional placeholders so you can safely publish a beautiful demo and swap in real details later.

> This template is not a real token. It has no wallet connection, no contract interaction, no backend, no audit claim and no fabricated tokenomics. Every placeholder is labelled SAMPLE or placeholder.

## What's inside

- `index.html` — hero, token info panels, roadmap, community links, FAQ, SEO/Open Graph meta
- `style.css` — responsive layout, animated hero (canvas stars, floating art), dark theme
- `script.js` — mobile nav, copy-contract button, star canvas, subtle parallax
- `README.md` — this file

## Publish on GitHub Pages (no build step)

1. Create a new GitHub repository, for example `moonk-landing`.
2. Upload or push these files to the repository root: `index.html`, `style.css`, `script.js`, `README.md`. The file must be named exactly `index.html` at the root.
3. On GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait a minute or two. Your site will be live at `https://YOUR-USERNAME.github.io/REPO-NAME/`.

Tip: to use a custom domain, add a file named `CNAME` containing only your domain, then configure the domain in Settings → Pages.

## Customize before any real launch

Search the files for `SAMPLE`, `placeholder`, `TBD`, `0xSAMPLE` and `#` links, then replace:

- Brand name, logo emoji and ticker (currently MoonCroak / MOONK)
- Contract address in the Token section (currently `0xSAMPLE_CONTRACT_ADDRESS_REPLACE_ME`)
- Social links for X, Telegram, Discord and DexScreener (currently `#` hrefs)
- Supply, tax, chain, token allocation and roadmap dates
- Page title, meta description and favicon in `index.html`

## Local preview

No build is needed. Either open `index.html` in a browser, or run a tiny static server from this folder:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000
